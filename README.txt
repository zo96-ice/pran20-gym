JEFFEYP'S GYM OS v8.9 MOV + MP4 VIDEO SUPPORT

Change:
- Workout videos now support BOTH .mov and .mp4.
- For every exercise video, the player tries:
  1. videos/[name].mov
  2. videos/[name].mp4
- If the .mov is missing or fails, it automatically falls back to .mp4.
- The on-screen placeholder shows which file it is trying.

Preserved:
- v8.7 Knee Hold Mode.
- v8.6 all finishers at end.
- Previous weight / Today weight adjustment.
- Exercise Weights manager.
- v8.4 visual base fixes.

Video references supported: 39

Run:
1. Unzip.
2. Put video files in the videos folder.
3. You may use either .mov or .mp4 filenames.
4. Open index.html in Chrome or Edge.
5. Press F11 for fullscreen.
